5 Languages 多言語単語帳 初版

並び：English → Indonesia → Esperanto → Türkçe → 日本語

使い方
1. index.html / style.css / words.js / app.js を同じGitHubリポジトリ直下へ置く。
2. GitHub Pagesを有効化する。
3. Safari等で開く。
4. 「データ」→「JSONを書き出す」で保存。iPhone/Macの保存先にOneDriveフォルダを選択する。
5. 復元時は「JSONを読み込む」で同じJSONを選択する。

注意
・通常の追加データはブラウザのlocalStorageにも保存されます。
・GitHubへ追加語を自動アップロードする設計ではありません。
・音声はWeb Speech APIを使用するため、端末・ブラウザにより声質やEsperanto対応状況が異なります。
・初版は動作確認用の少数語のみ収録しています。大量語彙は別JSONとして増やせます。
